````markdown
# ✨ MyBlog - Vue2 + TypeScript で作成した個人ブログ

Vue2 + TypeScript を使ってゼロから開発した完全自作のブログシステムです。UI フレームワークを一切使わず、すべてのコンポーネントを手作りしています。認証、テーマ切替、アニメーション、Markdown レンダリング、音楽プレイヤーなど多機能を統合しています。

## 🧭 開発の背景

最初は日々の仕事で役立つコードを整理する目的で始まりましたが、徐々に記事投稿、動的効果、国際化、趣味紹介など多機能なポータルへと進化しました。私自身の技術成長と心境の変化を反映する場でもあります。

## 📌 主な機能

- **権限管理**：ゲストモード、自動ログイン機能（localStorage の sessionId 使用）
- **レイアウト機能**：サイドバー折りたたみ、タブ履歴、i18n 切替、テーマ切替、全画面表示
- **動的ルーティング**：再帰的にルートを構築、非表示・無権限ページを自動除外
- **自作 UI コンポーネント**：メッセージ通知、画像プレロード、スクロールイベント管理など
- **ホームページ演出**：マウスに連動した背景動作、字幕アニメーション、遅延画像描画
- **記事ページ**：Markdown レンダリング、構造解析、目次・スクロール連携
- **メッセージページ**：開発者にメッセージを送信可能
- **「私について」ページ**：日本語での心境記録と来日理由の紹介
- **趣味ページ**：音楽プレイヤーにて日本語カバー曲を再生

## 🛠 使用技術

- Vue2 + TypeScript
- Vuex, Vue Router
- Less（テーマ用 mixin）
- PrismJS, markdown-it
- UI フレームワーク未使用（全て手作り）

## 🚀 開発環境の構築

```bash
git clone https://github.com/tearlighting/myblog.git
cd myblog
npm install
npm run serve
```
````
