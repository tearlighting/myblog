# About Page - Director's Notes

> This is not a UI document.
>
> This document describes the experience, emotion and story behind the About page.

---

# Goal

The About page is **not** a portfolio.

It is not a resume.

It is not a landing page.

It should feel like walking through someone's journey.

The user doesn't read it.

The user explores it.

---

# Core Interaction

The page is divided into four chapters.

Scrolling is always vertical.

Inside each chapter, the scroll drives a horizontal exploration.

After finishing one chapter, the page naturally continues to the next.

We intentionally DO NOT build a generic HorizontalExplorer.

Each chapter owns its own timeline and interaction.

Implementation is allowed to be completely manual.

Progress is more important than abstraction.

---

# Overall Feeling

Keywords:

- Quiet
- Atmospheric
- Personal
- Curious
- Calm
- Growing

Avoid:

- Startup landing page
- Generic portfolio
- "I'm a passionate frontend engineer"
- Empty motivational quotes
- Artificially poetic language

---

# Theme

The page should feel like

> visiting someone's room after they have lived there for years.

Not everything needs explanation.

Objects, fragments and moments should tell the story naturally.

---

# Chapter 1

## Working title

Beginning

## Purpose

Answer one question:

> Why does this page exist?

This chapter should not introduce skills.

Instead, it should explain why this page was created.

The visitor should slowly understand that this page is a record of growth rather than a portfolio.

### Possible Scenes

- quiet opening
- desk
- floating fragments
- notebook
- code
- keywords
- ending sentence

Possible ending:

> This isn't a portfolio.
>
> It's a record of how I got here.

---

# Chapter 2

## Working title

Journey

## Purpose

Show several moments that changed me.

Not a resume.

Not a timeline.

Instead:

A collection of important scenes.

Possible scenes:

- discovering JavaScript internals
- learning Object.defineProperty / Proxy
- rebuilding frontend knowledge
- moving to Japan
- Akihabara
- first custom PC
- broken CPU socket
- rebuilding the blog

Every scene should tell something about the author without directly saying it.

---

# Chapter 3

## Working title

Things I Keep Returning To

## Purpose

This chapter is not about hobbies.

It answers another question:

> What keeps bringing me back?

Possible topics:

- English
- Japanese
- Re:Zero
- DanMachi
- AI
- UI
- Design
- Building things

The chapter should feel freer than Journey.

Fragments instead of timeline.

---

# Chapter 4

## Working title

Projects

## Purpose

Everything shown before eventually became something real.

This chapter should reuse existing Project components whenever possible.

Projects are the conclusion of the journey.

Not the introduction.

---

# Ending

Avoid:

- Contact Me
- Hire Me
- Download Resume

Instead:

Leave the visitor with one simple feeling.

"I know this person a little better now."

Possible ending:

> That's all.
>
> For now.

---

# Important Principles

Never tell the user:

- I'm hardworking.
- I'm passionate.
- I'm creative.

Instead,

show moments that naturally lead the visitor to those conclusions.

---

# About the Author

The page should gradually reveal these ideas.

Not directly.

But through scenes.

Current observations:

- enjoys redesigning complex systems
- likes understanding how things work internally
- values growth more than perfection
- wants to leave traces of progress
- keeps rebuilding things instead of accepting the first solution
- prefers understanding over memorizing
- believes stories are stronger than self-description

---

# Current Direction

The About page is closer to

an interactive film

than

a portfolio website.

The user should feel like they walked through someone's journey,
not like they finished reading someone's resume.
