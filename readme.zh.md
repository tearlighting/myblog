# ✨ MyBlog - Vue2 + TS 自研个人博客系统

一个从 0 开始搭建的 Vue2 + TypeScript 博客系统，不使用任何 UI 框架，核心功能全部自研。项目集权限控制、响应式主题、动画效果、Markdown 解析、音乐播放等于一体，既是技术的实践场，也是情感的记录者。

## 🧭 项目初衷

这个博客系统最初是为了整理和记录工作中的代码片段，后来逐步扩展为文章管理、视觉动效、国际化和兴趣展示于一体的综合站点。它不仅是我技术成长的见证，也是我内心变化的反映。

## 📌 功能亮点

- **权限管理**：支持游客模式与自动登录，部分功能需要认证。
- **布局系统**：折叠菜单、页面标签、国际化切换、主题切换、全屏支持。
- **动态路由生成**：递归构建路由树，自动过滤隐藏项与无权限页面。
- **自研组件**：消息提示、图片预加载、全局滚动事件等。
- **首页特效**：鼠标悬浮背景动效、字幕动画、懒加载图像。
- **文章页**：支持 Markdown 渲染 + 高亮 + 锚点目录 + 滚动联动。
- **留言页**：用户可对站长留言。
- **关于我**：目前提供日语版，记录了来日动机与个人思考。
- **兴趣页**：音乐播放器，收录个人翻唱作品。

## 🛠 技术栈

- Vue2 + TypeScript
- Vuex、Vue Router
- Less + mixins
- PrismJS、markdown-it
- 无 UI 框架，组件自研

## 🚀 快速启动

```bash
git clone https://github.com/tearlighting/myblog.git
cd myblog
npm install
npm run serve
```
